# Kaapur Care

Website for Kaapur Care, laundry and dry cleaning in front of Tezpur Medical College, Bihaguri, Tezpur.

Live at https://kaapurcare.com (GitHub Pages, DNS on Namecheap).

## Editing

Everything is in `index.html`.

- Prices: the `ITEMS` list in the script near the bottom.
- WhatsApp number: `WA_NUMBER` in the same script.
- Plans, hours and address: search for the text in the HTML.

Push to `main` and the site updates in a minute or two.
